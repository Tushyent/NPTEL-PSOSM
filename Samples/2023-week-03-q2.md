## Question

Which of the following features is used by the credibility model- TweetCred?

## Options

- **A.** Tweet links
- **B.** Tweet Author
- **C.** Tweet network
- **D.** Tweet meta data

## Accepted answer

**A. Tweet links; B. Tweet Author; C. Tweet network; D. Tweet meta data**

## Explanation

TweetCred scores the credibility of a tweet on a 1-7 scale. The model combines features from the tweet content, the author, the surrounding retweet/mention network and tweet metadata. All four groups listed are used, so every option is accepted.

## Source citation

- **Topic:** Week 2.2: Trust and credibility - the TweetCred extension
- **Page:** Pages 215-217
- **Summary:** TweetCred uses all the features discussed in the credibility lectures and presents a credibility value from 1 to 7.
