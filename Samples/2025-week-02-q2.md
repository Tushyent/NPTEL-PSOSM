## Question

What does JSON stand for ?

## Options

- **A.** JavaScript Object Notation
- **B.** Java Standard Object Notation
- **C.** JSON Scripted Object Name
- **D.** Joint Syntax Object Network

## Accepted answer

**A. JavaScript Object Notation**

## Explanation

JSON stands for JavaScript Object Notation. It is a lightweight, human-readable format for structured key-value data and is one of the common formats returned by social-media APIs.
