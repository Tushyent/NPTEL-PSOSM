## Question

MongoDB stores data in a structure most similar to ____.

## Options

- **A.** JSON
- **B.** SQL
- **C.** XML
- **D.** None of the above

## Accepted answer

**A. JSON**

## Explanation

MongoDB is a document database. It stores records as JSON-like BSON documents inside collections, rather than as rows in relational SQL tables. XML is a markup format, not MongoDB's native storage model.

## Source citation

- **Topic:** Tutorial 3, Part 3: MongoDB and document storage
- **Page:** Pages 311-317
- **Summary:** MongoDB is a document-oriented NoSQL database that stores data in JSON/BSON document structures.
