## Question

Which of the following can be used in authentication for the Twitter API ?

## Options

- **A.** Bearer Token
- **B.** Client ID
- **C.** Client Secret
- **D.** None of the above

## Accepted answer

**A. Bearer Token; B. Client ID; C. Client Secret**

## Explanation

Twitter's API uses OAuth credentials. App-only authentication uses a bearer token, while OAuth 2.0 client credentials use a client ID and client secret. All three are valid authentication values, so the first three options are accepted.
