## Question

Creating a new file in a git repository adds it to :

## Options

- **A.** Tracked Files
- **B.** Untracked Files
- **C.** Remote Repository
- **D.** None of the Above

## Accepted answer

**B. Untracked Files**

## Explanation

A newly created file in a Git repository is untracked until it is added. `git add` moves it to the staging area, and a commit records it in the repository history. It is not automatically tracked or pushed to a remote.

## Source citation

- **Topic:** Tutorial 1: Git version control fundamentals
- **Page:** Pages 50-65
- **Summary:** Git tracks files through untracked, staged, committed and remote states; `git add` stages new files.
