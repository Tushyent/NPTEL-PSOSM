## Question

A row in SQL is called a ______ in MongoDB.

## Options

- **A.** Collection
- **B.** Field
- **C.** Index
- **D.** Document

## Accepted answer

**D. Document**

## Explanation

The mapping is: SQL table -> MongoDB collection, SQL row -> MongoDB document, and SQL column -> MongoDB field. A document is therefore the closest MongoDB equivalent of a row.

## Source citation

- **Topic:** Tutorial 3, Part 3: MongoDB terminology
- **Page:** Pages 311-317
- **Summary:** MongoDB stores documents inside collections; a collection is the table equivalent and a document is the row equivalent.
